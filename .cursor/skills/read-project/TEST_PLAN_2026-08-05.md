## 1. 统计「笔记条数」不含词频

| 编号 | 步骤 | 预期 | 结果 | 备注 |
|------|------|------|------|------|
| T1.1 | 若该书已有大词频本（上千条），打开「统计」 | 「笔记本」数量不含词频本；「笔记」条数远小于词频条数 |  | 原先会把 1 万+ 词频行算进去 |
| T1.2 | 对比「笔记 → 阅读笔记」里普通本条目总数 | 与统计页「笔记条数」大致一致（不含系统本、不含词频本） |  | 系统本本来就不计入 |
| T1.3 | 无词频本时打开统计 | 笔记条数仍正常，不为 0 也不报错 |  |  |
